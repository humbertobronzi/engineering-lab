# Case-002 — Legacy PC Cybersecurity Lab

## Project Overview

This project aims to repurpose an older desktop computer as a practical laboratory for IT infrastructure, Linux administration, virtualization, networking, and cybersecurity.

The existing Windows installation will initially be preserved as the host operating system. Linux will be evaluated as a virtual machine, depending on the hardware capabilities identified during the assessment.

## Objectives

- Assess the computer's hardware and current operating condition.
- Identify and document existing hardware and software components.
- Evaluate the feasibility of virtualization.
- Set up a Linux virtual machine.
- Practice system administration and network configuration.
- Explore security hardening, monitoring, and remote administration.
- Document technical procedures, tests, and results.

- The computer displayed a BIOS message indicating that its settings had been reset.
- The BIOS main menu was accessible.
- System Information confirmed the motherboard model, processor family, and installed memory.
- The computer has a history of intermittent startup behavior.
- No hardware changes or BIOS configuration modifications have been made during this initial inspection.

The cause of the BIOS reset and the intermittent startup behavior has not yet been confirmed.

## Methodology

The project follows a documented, incremental troubleshooting approach:

1. Record the original system condition.
2. Identify hardware and software components.
3. Investigate potential hardware and configuration issues.
4. Evaluate system compatibility and available resources.
5. Implement changes incrementally.
6. Validate each change through testing.
7. Document evidence, findings, and results.

No assumptions will be treated as confirmed findings without supporting evidence.

## Project Phases

- Hardware inventory and diagnostics

- Security configuration and testing
- Final validation and documentation
