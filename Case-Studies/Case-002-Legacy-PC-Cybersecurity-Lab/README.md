# Case-002 — Legacy PC Cybersecurity Lab

## Project Status

In progress.

## Objective

Repurpose an older desktop computer as a local laboratory for
cybersecurity, information security, Linux administration,
virtualization, networking, and remote access.

The existing Windows installation will initially be preserved
and used as the host operating system. Linux will be evaluated
as a virtual machine.

## Initial State

The computer is an older desktop system with an intermittent
startup history and an existing Windows installation.

Initial BIOS inspection identified:

- Gigabyte motherboard
- Intel Pentium processor family
- 4 GB installed memory
- GIGABYTE UEFI DualBIOS
- BIOS version F5
- BIOS dated 2012

The BIOS initially displayed a message indicating that its
settings had been reset.

## Methodology

- Document the original state before making changes.
- Identify hardware and software components.
- Diagnose existing problems.
- Make changes incrementally.
- Validate each change.
- Document evidence and results.
- Avoid assumptions before verification.

## Planned Areas

- Hardware assessment
- Windows host assessment
- Virtualization
- Linux virtual machine
- Networking
- Remote administration
- Security configuration
- Validation and documentation

## Documentation

Photos, screenshots, notes, configurations, test results,
and other evidence are maintained throughout the project.

Sensitive information will be removed or redacted before
public publication.
