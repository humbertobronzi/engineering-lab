# 01 — Initial Assessment

## Purpose

Document the physical and initial operational state of the
computer before making configuration or hardware changes.

## Initial Observations

- Older desktop computer.
- Gigabyte motherboard.
- Intel Pentium processor family.
- Existing Windows installation.
- 4 GB installed memory.
- VGA video output.
- Ethernet network interface.
- BIOS reported that its settings had been reset.
- Computer has a history of intermittent startup behavior.

## Evidence

Physical photographs and BIOS screenshots are stored in the
corresponding directories.

## Method

The computer was inspected and documented before making
configuration changes.
